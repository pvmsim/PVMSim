# PVMSim Documentation

## Documentation contents

This folder contains the documentation associated with PVMSim software version `0.1.0`.

- [`workflow.md`](workflow.md): concise GUI workflow, repository structure, installation options, smoke-test procedure, and release information.
- [`user_manual/`](user_manual/): complete PVMSim User Manual, its LaTeX source, and associated figures.

## User manual

The current manual documents PVMSim software version `0.1.0` and follows an independent document-version sequence.

- **Manual version:** `1.1`
- **Archived manual:** <https://doi.org/10.5281/zenodo.19040391>

The Zenodo record should be updated with the revised manual version before the final software release.
